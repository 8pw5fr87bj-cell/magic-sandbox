# Magic Sandbox

A VR magic sandbox for Meta Quest headsets: shape water, earth and life with your hands.

Play: https://8pw5fr87bj-cell.github.io/magic-sandbox/

In the headset's browser press **2. Enter VR**. On a computer, **Play on this computer** uses the mouse and keyboard.

This repository holds only the built files (version 1.0.0, build 7d93e62e0a): it is the copy an installed
app loads and updates from. The software and assets it is built from are listed in
`THIRD-PARTY-NOTICES.txt`.
